smash-stats

スマブラの戦績を記録する、個人用の道具

kogcmineng が自分のために作った道具です。家のPCで、キャプチャーボードの映像からスマブラSPの対戦の結果（キャラ・ステージ・勝敗）を読み取って記録し、 戦績のページに出します。

YouTube との連携

自分のプレイの録画を、自分の YouTube チャンネルに非公開で上げるために、YouTube Data API を使います。 使うのは作った本人のアカウントだけで、ほかの人のアカウントやデータには触れません。

  • 自分の録画を、自分のチャンネルに非公開でアップロードする
  • アップロードした動画の処理の状態を確かめ、題名と概要欄（対戦の一覧）を書き直す

プライバシーポリシー ／ 戦績のページ

This is a personal tool by kogcmineng. It records the results of the owner's own Super Smash Bros. Ultimate matches and uploads the owner's own gameplay recordings to the owner's own YouTube channel as private videos, using the YouTube Data API. Privacy Policy
